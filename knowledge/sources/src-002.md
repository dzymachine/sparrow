# The Divorce Process in California

Getting a divorce in California takes **at least 6 months** to finish. There are **4 main steps** in the process:

1. **Part 1: Start a divorce case** - One spouse files papers (Petition FL-100, Summons FL-110) to start the case and serves the other spouse. The respondent has 30 days to file a Response (FL-120).
2. **Part 2: Share financial information** - Both spouses exchange financial information (preliminary declaration of disclosure: FL-140, FL-142, FL-150) within 60 days.
3. **Part 3: Make decisions** - Make decisions about property/debt division, child custody/support, and spousal support.
4. **Part 4: Finalize the divorce** - Submit final paperwork (Judgment FL-180, Notice of Entry FL-190) to the court.
