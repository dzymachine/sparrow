# Raw Sources (`knowledge/sources/`)

- Source files should be named descriptively (e.g., `selfhelp-divorce-overview.md`, `family-code-760.md`).
- Frontmatter header should include:
  ```yaml
  title: "Official Page Title"
  url: "https://..."
  jurisdiction: "California"
  date_fetched: "YYYY-MM-DD"
  ```
